# **App Name**: heidless ai

## Core Features:

- Homepage: Homepage with Hero, Services, Portfolio, and Contact sections. Includes a Call to Action Section to link to Contact page.
- Portfolio: A portfolio section showcasing projects
- Contact Form: A contact form for inquiries.
- Brief Analyzer: Brief Analyzer: Uses a generative AI tool to summarize client briefs or mockups, providing a starting point for the design process.
- Navbar: Navigation bar links to each section of the Home page.
- Desktop width limit: Displays all page contents within 95% of screen width, when app is running on a desktop display.

## Style Guidelines:

- Primary color: Deep red (#D62828) to convey boldness and creativity, aligning with the agency's modern design approach.
- Background color: Dark navy blue (#003049) to provide a sophisticated, professional backdrop that allows content to stand out.
- Accent color: Bright orange (#F77F00) to highlight key interactive elements such as the Contact call to action, adding vibrancy and energy.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines to provide a modern and tech-forward feel, and 'Inter' (sans-serif) for body text to ensure readability and a clean aesthetic.
- Modern, clean layout with clear sections for each part of the homepage.
- Minimal, line-based icons to represent different services and expertise areas.
- Subtle transitions and hover effects to enhance user engagement and provide a smooth browsing experience.
